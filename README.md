# Neon Orb Dash 🚀

A fun and cool daily browser game created by Grok!

**Today's Game (November 12, 2026):** Neon Orb Dash

Control a glowing neon orb, collect cyan energy orbs for points, and dodge the falling red bombs!

## How to Play
- Open `index.html` in any modern browser (or use GitHub Pages if enabled)
- Use **Arrow Keys** or **WASD** to move
- Collect the glowing orbs → +10 points each
- Avoid the red spiked bombs!
- High score is saved in your browser

## Features
- Neon glow effects & particle explosions
- Smooth canvas rendering
- Local high score
- Zero dependencies — pure HTML/CSS/JS

Enjoy the daily fun! Come back tomorrow for a new game. 🎮
